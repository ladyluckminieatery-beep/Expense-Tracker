# 💰 Expense Tracker

A responsive web application that helps users record, manage, and keep track of their personal expenses. The project was built with **HTML, CSS, and JavaScript** to practice frontend development and interactive web functionality.

## ✨ Features

* Add and record expenses
* View recorded expenses
* Track expense amounts
* Calculate and display expense totals
* Delete expenses
* Interactive user interface
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling, layout, and responsive design
* **JavaScript** — Application logic, calculations, DOM manipulation, and user interactions

## 🚀 How to Use

1. Open the Expense Tracker.
2. Enter the required expense information.
3. Add the expense to your list.
4. Review your recorded expenses and total spending.
5. Delete an expense when it is no longer needed.

## 🎯 Purpose

This project was created to strengthen my skills in **HTML, CSS, JavaScript, DOM manipulation, event handling, and building interactive web applications**.

## 📱 Responsive Design

The application is designed to provide a usable experience across different screen sizes, including desktop and mobile devices.
